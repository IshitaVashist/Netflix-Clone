<h1 align="center"> 🎬🍿 Netflix Clone - A Quick and Simple Streaming App 🍿🎬 </h1>

<h2 align="center">This is a simple Netflix clone built in just 3 hours using only HTML and CSS. It aims to replicate the sleek and modern design of Netflix's homepage, offering a clean layout with a responsive and user-friendly interface.</h2>

## 🚀 **Features**

- 🎥 **Movie & TV Show Listings**: A dynamic list of popular movies and TV shows, with posters and titles for each.
- 🌟 **Responsive Design**: Optimized to work seamlessly across all devices—desktop, tablet, and mobile.
- 🎨 **Modern UI**: A clean, minimalistic user interface with Netflix-like visual appeal.
- 🖥️ **Interactive Elements**: Hover effects on posters and a video background to mimic the Netflix experience.
- 🔍 **Search Functionality**: A search bar that allows you to filter movies and shows quickly.

## 🛠️ **Technologies Used**

- **Frontend**: HTML, CSS
- **Styling**: Pure CSS (No JavaScript, React, or other frameworks)

## 🏆 Why Choose This Clone?

- 🎬 **Sleek UI**: Built to replicate the look and feel of Netflix's homepage in just **3 hours** using only **HTML** and **CSS**.
  
- ⚡ **Speedy Development**: Achieved in **3 hours**, focusing on the core design and functionality.

- 📱 **Responsive Design**: The layout is fully optimized for mobile and desktop devices, ensuring smooth user experience.

- 🧑‍🎨 **User-Centered Design**: Focused on clean aesthetics and ease of use.

## 🌟 **Usage**

- 🔎 **Explore Content**: Browse through the movie and TV show listings by scrolling through the homepage.
- 🎨 **Enjoy the Interface**: Hover over movie posters to see a subtle hover effect.
- 🖥️ **Watch in Style**: The homepage features an interactive video background, mimicking the Netflix experience.

## 🏗️ **Installation**  

### 📋 **Prerequisites:**  
     - Node.js (v18+)
     - OpenWeatherMap API key  

### 📝 **Steps to Run the Project:**  

1️⃣ **Clone the Repository**  
```sh
git clone https://github.com/yourusername/animated-weather-app.git
cd animated-weather-app
```

2️⃣ **Install Dependencies**  
```sh
npm install
```

3️⃣ **Set Up Environment Variables**  
- OpenWeatherMap API key  

4️⃣ **Start the Development Server**  
```sh
npm start
```

5️⃣ **Visit the Application**  
    Open Local Host Server
